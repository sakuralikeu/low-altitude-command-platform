# aicoding实操案例无人机接口 - Mock数据文档

# 接口1：飞行总览统计（openTotalDataByDept）

### 返回参数说明

| 参数名           | 类型      | 说明     |
| ------------- | ------- | ------ |
| shelterNum    | Integer | 方舱数量   |
| flyLineNum    | Integer | 飞行航线数量 |
| achieveNum    | Integer | 成果数量   |
| flyerNum      | Integer | 飞手数量   |
| workOrderNum  | Integer | 工单数量   |
| recordCount   | Integer | 飞行架次次数 |
| flyPlaneNum   | Integer | 飞行计划数量 |
| flightLength  | String  | 飞行里程   |
| durationHours | String  | 飞行时长   |

## 接口2：分页查询AI识别结果（openAssociatedFlyRecord）

### 返回参数说明

| 参数名                | 类型                              | 说明                          |
| ------------------ | ------------------------------- | --------------------------- |
| total              | Long                            | 总记录数                        |
| rows               | List<AssociatedFlyRecordRespVO> | 飞行记录列表                      |
| rows.flyRecordId   | Long                            | 飞行记录主键ID                    |
| rows.flyRecordName | String                          | 飞行记录名称                      |
| rows.flyLineId     | Long                            | 飞行航线主键ID                    |
| rows.flyLineName   | String                          | 飞行航线名称，默认值为"指点飞行"           |
| rows.flyerId       | Long                            | 飞手主键ID                      |
| rows.flyerName     | String                          | 飞手名称                        |
| rows.createTime    | String                          | 起飞时间，格式：yyyy-MM-dd HH:mm:ss |
| rows.shelterId     | Long                            | 方舱主键ID                      |
| rows.shelterName   | String                          | 方舱名称                        |
| code               | Integer                         | 状态码                         |
| msg                | String                          | 返回消息                        |

---
