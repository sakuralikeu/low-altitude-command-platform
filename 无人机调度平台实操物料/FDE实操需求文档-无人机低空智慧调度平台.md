# FDE第二期工作坊 - 实操需求文档

## 场景：无人机低空智慧调度平台（大屏可视化）

---

## 一、项目背景

公安、交管部门需对辖区道路、重点区域开展无人机常态化巡航。为满足低空无人机常态化管控需求，需建设一套**无人机低空智慧调度平台**，实现"态势一张图"的可视化数据能力。

平台通过统一调度一架或多架无人机，AI自动识别交通事故、车辆、行人、烟雾等目标，最终通过**大屏**展示飞行数据统计情况，为无人机巡检提供分析决策数据支撑。

---

## 二、技术栈要求

| 类别    | 技术选型                                                       |

| 前端框架  | Vue 2.x（2.6.14）或 Vue 3，Vue CLI 5.x 脚手架                     |

## 三、需要实现的模块

### 模块1：登录页面

- 页面名称："无人机低空指挥调度平台"
- 包含：用户名、密码、验证码输入
- 登录成功后跳转至大屏主页；大屏登出后跳回登录页

### 模块2：顶部导航栏

- **系统标题**：显示"无人机低空指挥调度平台"
- **系统信息**（左上角）：实时时间、星期、日期、天气
- **用户区域**（右上角）：用户名、首页按钮、用户头像

### 模块3：左侧区域

#### 3.1 飞行总览模块

- 展示总方舱数、总飞手数等飞行总览统计数据
- 接口：`GET /openTotalDataByDept`

#### 3.2 飞行案例 TOP10

- 列表展示最新完成的飞行数据 TOP10，按执行时间降序
- 字段：序号、飞行编号、飞行航线、飞行记录名称、执行时间、执行设备
- 卡片形式纵向排列展示
- 接口：`GET /openAssociatedFlyRecord`

### 模块4：右侧区域

#### 4.1 飞行任务排行榜

- 按时间范围筛选：今日、本周、本月、本年、累计
- 展示四类任务状态数量：待派发、派发中、已接单、已结单
- 选择某状态后，展示该周期内各组织的任务数量及占比
- 接口：`POST /openTaskOverview`

#### 4.2 飞行统计分析

- 按各组织聚合统计：飞行架次、飞行里程、飞行时长
- 统计时间范围：2024年1月1日至今
- 接口：`POST /openNewTotalDataByDay`

### 模块5：中央地图区域

- 底图支持：卫星图 / 电子地图 / 暗色主题切换
- 地图中心点默认为设备所在地，无设备时默认上海

## 六、验收标准

1. 大屏整体布局完整，左/中/右三栏 + 顶部导航
2. 飞行总览数据正确展示（方舱数、飞手数等）
3. 飞行案例 TOP10 按时间降序展示，卡片样式
4. 飞行任务排行榜支持时间筛选（今日/本周/本月/本年/累计），状态切换展示各组织占比
5. 飞行统计分析展示各组织飞行架次、里程、时长
6. 中央地图可切换底图类型（卫星/电子/暗色）
7. 大屏在不同分辨率下自适应，无拉伸、无裁切
