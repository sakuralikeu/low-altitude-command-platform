## 二、本期实施范围（6 场景，全部规则可解释、无外部 AI 依赖）

### 模块 A · 禁飞区合规校验（S5）
- 后端：禁飞区数据（上海虹桥机场净空区、龙华机场周边、临时活动区，多边形坐标），射线法点-in-多边形判定
- 实时链路：遥测快照生成时同步计算"是否进入禁飞区"，违规 → SSE 告警事件 + 列表接口
- 前端：高德地图 Polygon 图层（暗色/电子/卫星三模式同步显示）；演示模式用 CSS 简化绘制；违规飞机标记红色脉冲 + 告警中心新增类型

### 模块 B · 空域冲突预警（S3）
- 后端：任意两架飞行中飞机水平距离（Haversine）与垂直高度差 → 双阈值（预警 <800m、严重 <400m）→ 冲突事件流 + 冲突列表接口
- 前端：告警中心类型"冲突预警"；地图上冲突对连线提示（可选，P1）

### 模块 C · 电量续航预测与返航提醒（S4）
- 后端：机型参数表（M350 RTK/M30T/M3E 额定续航、巡航速度、安全返航系数 1.25）；实时计算：预计可飞剩余分钟、按任务点距离反推返航所需电量，电量 < 返航所需 × 1.25 → 低电量预警
- 前端：飞机 popover 增加"预计剩余 X 分钟 · 建议返航 Y% 时返航"；KPI 告警类型扩展

### 模块 D · 任务智能调度推荐（S2 + S8）
- 后端：调度推荐引擎——候选过滤（非待命、电量≥返航阈值、机型能力匹配）→ 综合评分（距离 40% + 电量 30% + 空闲度 20% + 能力 10%）→ 返回排序 + **可解释理由**（如"距目标 2.1km，电量 82%，预计续航 41min"）；支持"应急"任务类型（优先+最近机权重上调）
- 前端：右侧面板新页签"智能调度"——任务类型/优先级选择 → 推荐列表（评分条+理由）→"执行派发"写入调度记录并置任务状态

### 模块 E · 巡检工单闭环（S7）
- 后端：工单数据 + 状态机（待接收→已接收→执行中→已完结），支持按航线周期（日/周）自动生成下一轮巡检计划；工单统计接口（与 S1 排行榜口径一致）
- 前端：右侧面板页签"工单管理"——状态筛选 + 列表 + 状态流转按钮 + 自动生成计划开关

### 模块 F · 设备健康与维护预测（S10）
- 后端：设备目录（8 台，关联飞机/方舱）+ 累计飞行时长（由演示数据推导）+ 部件寿命阈值（电池循环 300 次、电机 800h、桨叶 400h）→ 健康分（100-阈值剩余比加权）与保养建议（"3 天后需保养电机"）
- 前端：右侧面板页签"设备健康"——健康分环/条 + 保养倒计时列表

### 演示性模块 G · AI 识别事件流（S6 的合规演示版）
- 仅作事件流演示：模拟识别事件（交通事故/烟雾/聚集，带置信度 0.72–0.96），标注"演示数据 · 待接入识别模型"；处置闭环（确认→转派→归档）真实可用
- 位置：并入"工单管理"页签副区，不单独占位

## 四、API 契约（新增，全部 `Bearer` 鉴权，与现有错误格式一致）

```
GET  /api/v1/geo/no-fly-zones          → { data: { rows: NoFlyZone[] } }
GET  /api/v1/geo/conflicts             → { data: { rows: ConflictAlert[] } }
GET  /api/v1/aircraft/health           → { data: { rows: AircraftHealth[] } }
GET  /api/v1/dispatch/candidates?taskType=patrol|inspect|emergency&lng=&lat=&priority=
     → { data: { rows: DispatchCandidate[] } }   // 含评分与理由
POST /api/v1/dispatch/tasks             { taskType, lng, lat, priority, aircraftId? }
     → { data: { taskId, aircraftId, etaMinutes } }
GET  /api/v1/work-orders?status=        → { data: { rows: WorkOrder[], totals } }
POST /api/v1/work-orders/:id/transition { to: 'received'|'executing'|'completed' }
     → { data: WorkOrder }
POST /api/v1/work-orders/generate       { lineId, period: 'daily'|'weekly' }
     → { data: { generated: number } }
GET  /api/v1/events/ai-recognition      → { data: { rows: AiRecognitionEvent[] } }
SSE  /api/v1/realtime/aircraft          // 扩展事件类型: nofly / conflict / low-battery
```

类型：`NoFlyZone{ id,name,kind:'airport'|'temporary'|'restricted',points:[lng,lat][],enabled }`
`ConflictAlert{ id,aId,aName,bId,bName,horizontalM,verticalM,severity:'watch'|'critical',time }`
`DispatchCandidate{ aircraftId,name,model,score,reasons:string[],etaMinutes,batteryPercent }`
`WorkOrder{ id,title,lineName,orgName,status,createdAt,dueAt,aircraftName? }`
`AircraftHealth{ aircraftId,name,model,flightHours,totalFlights,healthScore,parts:[{part,limit,used,remainingHours,advice}] }`
